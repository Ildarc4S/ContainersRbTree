# containers

Для сборки контейнеров используется `docker`.
Необходимые зависимости: `docker`.

1. Сборка `docker`:
```bash
make docker-build
```
2. Сборка проекта через `cmake`:
```bash 
make build 
```
3. Доступные команды: 
```bash
make help
```
Сайт с покрытием кода доступен по ссылке:
[Project Pages](https://ildarc4s.github.io/s21_containers/)
