# Cвойства КЧ дерева

1. Каждый узел является либо красным, либо черным.
2. Корень дерева является черным узлом.
3. Каждый лист дерева (NIL) является черным узлом.
4. Если узел красный, то оба его дочерних узла черные.
5. Для каждого узла все простые пути от него до листьев, являющихся потомками данного узла, содержат одно и то же количество черных узлов.


# Cлучаи удаления узла из кч дерева

**Замечание:**

`B` - черный узел
`R` - красный узел
`NIL` - листовые узлы (всегда черные). В коде представляются как `nullptr`.
`y` - удаляемый узел или его преемник
`x` - узел, который займет место y (может нарушить свойства)

Функция `transplant(u, v)`:
Заменяет узел `u` на узел `v`, обновляя связи:
1. Если `u` — корень, `v` становится новым корнем.  
2. Если `u` — левый потомок своего родителя, родитель теперь ссылается на `v`.  
3. Если `u` — правый потомок, аналогично.  
4. Родитель `v` становится равным родителю `u`.

## 1. Удаление узла с одним левым потомком
**Исходное дерево**:
```
      10
     /  \
    5    15
   /    /  \
  3    12   18
```
**Удаляем узел `5`** (имеет только левого потомка `3`):
1. `y = 5` (удаляемый узел).  
2. `x = 5.left = 3` (единственный потомок).  
3. `transplant(5, 3)` — поддерево с корнем `5` заменяется на поддерево с корнем `3`.  

**Результат**:
```
      10
     /  \
    3    15
        /  \
      12    18
```
- Узел `3` занял место `5`.  
- Родитель `10` теперь ссылается на `3` вместо `5`.

## 2. Удаление узла с правым потомком**

**Исходное дерево**:
```
      20
     /  \
   10    30
     \     \
     15    35
```
**Удаляем узел `10`** (имеет только правого потомка `15`):
1. `y = 10`.  
2. `x = 10.right = 15`.  
3. `transplant(10, 15)` — поддерево `10` заменяется на `15`.  

**Результат**:
```
      20
     /  \
   15    30
          \
          35
```
- Узел `15` занял место `10`.  
- Родитель `20` теперь ссылается на `15` вместо `10`.

cлучай удаление корня с одним потомком обрабатывается функцией `transplant()`. И он входит внутрь предыдущих случаев. Но пример:

**Исходное дерево**:
```
    50
     \
     60
    /  \
   55   70
```
**Удаляем корень `50`** (имеет только правого потомка `60`):
1. `y = 50`.  
2. `x = 50.right = 60`.  
3. `transplant(50, 60)` — `60` становится новым корнем.  

**Результат**:
```
     60
    /  \
  55    70
```
- Дерево "поднимается" на уровень вверх.

## 3. Удаление узла с двумя потомками.
**Исходное дерево**:
```
    A
   / \
  B   D(z) ← удаляемый узел
 /   /  \
C   E    F
   / \  / \
  G   H I  K
```
**Обозначения**:
- `z` — удаляемый узел (`D`).
- `y` — преемник (минимальный в правом поддереве `z`).
- `x` — узел, который займет место `y` (обычно `y.right`, так как `y` не имеет левого потомка).

### **Шаг 1: Находим преемника `y`**
Ищем минимальный узел в правом поддереве `z`:
- `y = minimum(D.right) = I` (минимальный в поддереве это `I`).

**Дерево после выбора `y`**:
```
    A
   / \
  B   D(z)
 /   /    \
C   E      F
   / \   /  \
  G   H I(y) K
```
- `y = I`, `x = I.right = NIL` (потомок, который займет место `y`).

### **Шаг 2.1: Если `y` не прямой потомок `z`**
Случай, когда `y` (преемник) не является непосредственным правым потомком `z` (т.е. `y ≠ z.right`).  
В нашем примере: `I ≠ D.right` (`D.right = F`), поэтому:

1. **Перевешиваем `x` (`NIL`) на место `y` (`I`)**:
   - `transplant(y, x)`:
   - Родитель `I` (`F`) теперь ссылается на `NIL`.
   - Родителем `x = NIL` становится `F`.

**Промежуточное состояние**:
```
    A
   / \
  B   D(z)
 /   /   \
C   E     F
   / \   / \
  G   H NIL K
```
После трансплантации `y` становится отдельным узлом
```
I(y)
```

2. **Переносим правое поддерево `z` к `y`**:
   - `y.right = z.right` (`I.right = F`).
   - `F.p = I`.
```
I(y)
  \
   F
  / \
 NIL K
```

### **Шаг 2.1: Если `y` прямой потомок `z`**
Отойдем немного от нашего случая и временно рассмотрим другое дерево:
```
    A
   / \
  B   D (z)   ← удаляемый узел
 /   / \
C   E   F(y)   ← `y` — прямой потомок `z`
   / \   \
  G  H   I(x)  

```
В такой ситуации `y = minimum(D.right) = F`.
И `x` равен `y.right` (`I`), а `x.p` равняется `y` (`F`).
Так как `y` уже находится в удобной позиции, нам не нужно его отделять от всего дерево, оно аккуратно встанет на нужное место при замене `z` (`D`) на него. В дальнейшем необходимо будет просто перевезать левого потомка `y` (`F`) на левого потомка `z` (`D`). Вернемся к нашему изначальному дереву и продолжим рассматривать алгоритм.

### **Шаг 3: Заменяем `z` на `y`**
1. `transplant(D, I)` — узел `I` становится на место `D`.
2. Переносим левое поддерево `z` (`E`) к `y` (`I`):
   - `y.left = z.left` (`I.left = E`).
   - `y.left.p = y` (`E.p = I`).

**Финальное дерево**:
```
    A
   / \
  B   I(y)
 /   /    \
C   E       F
   / \     /  \
  G   H NIL(x) I
```

- Узел `I` занял место `D`, сохранив структуру дерева.

# Случаи необходимости балансировки

1. `y` был корнем, а теперь новым корнем стал красный потомок `y`.
```
  58(B)
  /
36(R)
```
После удаления `y = 58(B)`:
```
36(R)
```
Нарушается свойство 2.
2. `x` и его родитель были красными.
```
    30B
   /   \
 20R    40B
 /  \    / \
10B  25R 35B 50B
    /  \
  22B  28R
     \
     23R
```
После отвязки `y = 22(B)` от дерева получим:
```
    30B
   /   \
 20R    40B
 /  \    / \
10B  25R 35B 50B
    /  \
  23R  28R
```
Ну и дальше после остальных шагов по удалению:
```
    30B
   /   \
 20R    40B
 /  \    / \
10B  25R 35B 50B
    /  \
  23R  28R
```
Так и получаем что `x = 23(R)` и его родитель красные. Таким образом будет нарушение свойства 4.
3. При перемещении `y` в дереве приводит к тому, что любой простой путь, ранее содержавший `y`, теперь имеет на один черный узел меньше. 
До удаления `20(B)`:
```
      30B
     /   \
   20B    40B
   /  \     / \
 10B  25B 35B 50B
```
После удаления `20(B)`:
```
     30B
    /   \
  25B    40B
  /       / \
10B     35B 50B
```
Таким образом, для всех предков `y` оказывается нарушенным свойство 5.

# Случаи балансировки кч дерева 

**Замечание:**
`RB` - узел либо красного либо черного цвета
`R` - узел красного цвета
`B` - узел черного цвета
`x.p` - родитель узла `x`
`x` - узел, который нарушает свойства кч дерева 
`w` - брат узла `x`

## Случай 1: Брат узла x — красный
**Пример:**
```
     B (x.p)
     /   \
A(x,B)   D(w,R) 
 / \      / \
 ...   C(B)   E(B)
        / \   / \
        ...   ...
```

**Шаги:**
1. Меняем цвета: x.p(B на R), w(R на B)
2. Левый поворот вокруг x.p(B)
3. Новый брат x - C(B), переходим к случаю 2/3/4

**Результат:**
```
      D(R)
     /   \
B(x,B)   E(B)
 /   \    / \
A(B) C(B) ...
/ \   / \
...   ...
```

## Случай 2: Брат w - черный, оба потомка черные
**Пример:**
```
     B(x.p,RB)
     /   \
A(x,B)   D(w,B)
 / \      / \
 ...   C(B)   E(B)
       / \    / \
       ...    ...
```

**Шаги:**
1. Перекрашиваем w в R
2. Перекрашиваем x.p в B
3. x ← x.p(B) Теперь х это его родитель.

**Результат:**
```
     B(x,RB)
    /   \
A(B)   D(R)
/ \    / \
...  C(B) E(B)
     / \   / \
     ...   ...
```
Если x.p изначально был цвета R, цикл завершится после перекрашивания(свойство 4 не нарушается).

## Случай 3: Брат w - черный, левый потомок R, правый B
**Пример:**
```
     B(x.p,RB)
     /   \
A(x,B)   D(w,B)
 / \     /  \
 ...   C(R) E(B)
       / \  / \
       ...  ...
```

**Шаги:**
1. Меняем цвета: w (B на R), C (R на B)
2. Правый поворот вокруг w
3. Теперь правый потомок нового w - узел с цветом R (случай 4)

**Результат:**
```
     B(x.p, RB)
     /  \
A(x,B)  C(w,B)
 / \     /  \
 ...    ... D(R)
            /  \
          ...  E(B)
                / \
                ...
``` 

## Случай 4: Брат w - черный, правый потомок R
**Пример:**
```
     B(x.p,RB)
     /   \
A(x,B)   D(w,B)
 / \     /   \
 ...   C(RB)  E(R)
       / \   / \
       ...   ...
```

**Шаги:**
1. Присвоение w цвета x.p
2. Присвоение x.p цвета B
3. Присвоение правому потомку w цвета B
4. Левый поворот вокруг x.p
5. x ← корень (завершение). Теперь x указывает на корень (цикл балансировки завершится).

**Результат:**
```
     D(x,RB)
    /      \
  B(B)    E(B)
  /  \     / \
A(B) C(RB) ...
/ \   / \
...   ...
```
