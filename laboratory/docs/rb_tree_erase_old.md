Удаляемый элемент будем обозначать `x`.
1. `x` не имеет потомков. 
```
   |
   x
 /  \
NIL NIL 
```
Просто заменяем x на `NIL`.
```
   |
  NIL 
```

2. `x` имеет 1ого потомка.
```
   |
   x
 /  \
/\  nil 
--
```
Заменяем `x` потомком:
```
   |
  /\ 
  --
```
3. `x` имеет два потомка:
```
   |
   x
  /  \
 /\  /\
 --  --
```
Нужно найти максимальный элемент в левом поддереве. Копируем максимальный элемент на место `x` и удаляем максимальный элемент из поддерева. Получаем первые две ситуации.

При удалении возникает три ситуации:

1. `x` - красный
```
   x(r)
  / \
NIL NIL
```
Просто заменяем `x` на `NIL`.
2. `x` - черный с поддеревом. Если подумать, то поддерево состоит только из одного красного ребенка и `NIL` узлов, иначе правило черной глубины нарушится.
```
    x(b)
    /  \
  y(r) NIL
  / \
NIL NIL
```
`y` перемещаем на место `x` и меняем цвет на `b`.
3. `x` - черный без потомков
```
  x(b)
  / \
NIL NIL
```
В этом случае рассмотрим следующую задачу: 
Пусть было корректное КЧ дерево и черная вершина `x`. Вместо `x` подвесили дерево с черным корнем и черная глубина уменьшилась на 1.Считаем что это дерево - правый сын своего родителя. Если родителей нет, то все хорошо и делать нечего.

`a` - родитель поддерева из которого удалили x.

Было:
```
 |
/\ h = n
--
```

Стало:
```
 |
/\ h = n-1
--
```

2.1) `a` - красная вершина
```
 a(r)
 / \
b  /\
   --
```
Есть ли у `b` хотя бы 1 `красный` сын?
2.1.1) Есть:
```
    a(r)
   /   \
   b   /\ n-1 
  /  \ --
 /\  c(r)
 --   / \
n-1  /\ /\
     -- --
    n-1  n-1 
```
Делаем левый поворот вокруг `c` и после правый поворот вокруг `c`. Получаем:
```
   c(r)
  /    \
 b(b)  a(b)
 /  \    /  \
/\  /\  /\  /\
--  --  --  --
n-1 n-1 n-1 n-1
```
2.1.2) Нет:
```
    a(r)
   /   \
  b(b) /\ n-1 
  / \  --
 /\ /\
 -- --
n-1  n-1 
```
Перекрашиваем `b` в `red`, а `a` в `black`. Получаем:
```
    a(b)
   /   \
  b(r) /\ n-1 
  / \  --
 /\ /\
 -- --
n-1  n-1 
```
2.2)  `a` - черный узел
```
 a(b)
 / \
b  /\ n -> n-1
   --
```
2.2.1) Пусть `b` - красный
```
  a(b)
 /   \
b(r) /\
 \   --
  c(b)
```
Есть ли у `c` красный сын?
2.2.1.1) Есть:
```
  a(b)
 /   \
b(r) /\ n-1
 \   --
  c(b)
  /
d(r)
 /  \
/\  /\
--  --
n-1 n-1
```
Повернем влево вокруг `c` и затем повернем вправо. Получим:
```
   c(b)
  /   \
b(r)  a(b)
 \      \
 d(b)   /\
 / \    --
/\ /\   n-1
-- --
n-1 n-1
```
2.2.1.2) Нет:
```
   a(b)
   /  \
 b(r) /\ n-1
 / \  --
/\ c(b)
-- /  \
n /\  /\
  --  --
  n-1 n-1
```
Совершаем поворот вправо вокруг `b` Получим:
```
 b(b)
 /  \
/\  a(b)
--  /   \
n  c(r) /\ n-1
   /  \ --
  /\  /\
  --  --
  n-1 n-1 
```
2.2.2) `b` - черный:
```
 a(b)
 /   \
b(b) /\ n -> n-1
     --
```
Есть ли у `b` красные дети?
2.2.2.1) Есть:
```
  a(b)
  /   \
 b(b) /\ n-1
 / \  --
/\ d(r)
--
n-1
```
Совершаем поворот влево вокруг `d`. Получаем:
```
  d(b)
  /   \
 b(b) a(b)
 /     \
/\     /\
--     --
n-1    n-1
```
2.2.2.2) Нет:
```
  a(b)
  /   \
 b(b) /\ n-1
 / \  --
/\ /\ 
-- --
n-1 n-1
```
Перекрашиваем `b` в `red` и рекурсивно проверяем вверх.
```
  a(b)
  /   \
 b(r) /\ n-1
 / \  --
/\ /\ 
-- --
n-1 n-1
```
