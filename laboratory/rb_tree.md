### 📌 **Обозначения:**
- **x** — вставленный красный узел (новый)
- **y** — родитель `x` (красный, иначе нет нарушения)
- **g** — дед `x` (обязательно чёрный, иначе было бы два красных подряд)
- **u** — дядя `x` (брат `y`)

---

### 🔴 **Случай 1: Дядя (u) красный**
**Исходное состояние:**
```text
     g(b)
    /   \
  y(r)   u(r)
  /
x(r)
```

**Действия:**
1. Перекрашиваем `y` и `u` в чёрный
2. Перекрашиваем `g` в красный
3. Рекурсивно проверяем `g` (теперь он красный, может нарушить свойства)

**Результат:**
```text
     g(r)
    /   \
  y(b)   u(b)
  /
x(r)
```

**После рекурсивной обработки корень станет чёрным:**
```text
     g(b)
    /   \
  y(b)   u(b)
  /
x(r)
```

---

### ⚫ **Случай 2: Дядя (u) чёрный**
Разделяется на две подситуации:

#### **2.1. Линейная конфигурация (x — левый ребёнок y)**
**Исходное состояние:**
```text
     g(b)
    /   \
  y(r)   u(b)
  /
x(r)
```

**Действия:**
1. Правый поворот вокруг `g`:
   ```text
       y(r)
      /   \
    x(r)   g(b)
            \
             u(b)
   ```
2. Перекрашиваем:
   - `y` в чёрный
   - `g` в красный

**Результат:**
```text
       y(b)
      /   \
    x(r)   g(r)
            \
             u(b)
```

#### **2.2. Треугольная конфигурация (x — правый ребёнок y)**
**Исходное состояние:**
```text
     g(b)
    /   \
  y(r)   u(b)
    \
    x(r)
```

**Действия:**
1. Левый поворот вокруг `y`:
```text
     g(b)
    /   \
  x(r)   u(b)
  /
y(r)
```

2. Теперь сводится к случаю 2.1 (линейная конфигурация)

**После обработки 2.1:**
```text
       x(b)
      /   \
    y(r)   g(r)
            \
             u(b)
```

---

### ✅ **Итоговые правила:**
1. **Если дядя красный** → простое перекрашивание (без поворотов).
2. **Если дядя чёрный**:
   - Сначала добиваемся линейной конфигурации (поворотом, если нужно).
   - Затем делаем поворот вокруг деда и перекрашиваем.

---

### 🌰 **Пример полной балансировки**
Вставка последовательности `10, 5, 15, 3, 7, 12, 20`:

1. `10` → корень (чёрный).
2. `5` → красный, без нарушений.
3. `15` → красный, без нарушений.
4. `3` → нарушение (родитель `5` красный, дядя `15` красный → **Случай 1**).
5. `7` → красный, без нарушений
6. `12` и `20` → аналогичные проверки.

Итоговое дерево:
```text
        10(B)
       /    \
     5(B)   15(B)
    /   \   /   \
  3(R) 7(R)12(R)20(R)
```
